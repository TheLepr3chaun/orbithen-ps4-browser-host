04 / PKG workflow

GUIDED

Package installation must be performed by a compatible console-side installer after HEN is active. This dashboard cannot install PKGs itself.

  1. Confirm HEN loaded successfully on the target host.
  2. Use PKG files you own or are authorized to use.
  3. Transfer with a supported USB or network workflow.
  4. Install with a compatible console-side package tool.
